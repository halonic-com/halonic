# std.sha256

- Status: active
- Since: 0.1.0
- Source: HAL-104 (plan 4.1, 7.3); `sha256Hex` in the old util package (`packages/core/util`) at 784f78d

The SHA-256 function shall return the FIPS 180-4 digest of its input, hashing text as UTF-8, without using platform cryptography.

## Examples

- Given "abc", when it is hashed, then the hex digest is `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`.
- Given the empty text, when it is hashed, then the hex digest is `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`.
- Given one million times "a", when it is hashed, then the hex digest is `cdc76e5c9914fb9281a1c7e284d73e67f1809a48a497200e046d39ccc7112cd0`.
- Given random messages of every length from 0 to 200 bytes, when each is hashed, then every digest equals `node:crypto`'s.
