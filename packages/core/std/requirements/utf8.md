# std.utf8

- Status: active
- Since: 0.1.0
- Source: `utf8.encode` and `utf8.decode` in the old util package (`packages/core/util`) at 784f78d

The UTF-8 encoder and decoder shall give the same bytes and text as the WHATWG `TextEncoder` and `TextDecoder` (with default options), without using them.

If the decoder meets an invalid byte sequence, then it shall write one U+FFFD for it and carry on with the next byte that can start a sequence.

## Examples

- Given "€", when it is encoded, then the bytes are `e2 82 ac`.
- Given a lone surrogate U+D800, when it is encoded, then the bytes are `ef bf bd` (U+FFFD).
- Given the bytes `ef bb bf 61`, when they are decoded, then the text is "a": the byte order mark is dropped.
- Given the bytes `e2 82 41`, when they are decoded, then the text is U+FFFD followed by "A".
- Given 2,000 generated byte strings, when each is decoded, then every result equals `TextDecoder`'s.
