# code-editor.focus-ring

- Status: active
- Since: unreleased
- Source: HAL-14377 (C361 FE2); kit spec 24.7; WCAG 2.4.7

The code editor shall show that it has focus with the kit's inset focus ring: a 2px ring in the accent colour inside its edge, drawn as a shadow over a transparent 2px outline at −2px, and in high contrast, which drops the shadow, shall draw a 2px `Highlight` ring in the same place.

## Examples

- Given the editor has focus in light or dark mode, then a 2px accent ring shows inside its edge.
- Given high contrast is on and the editor has focus, then a 2px `Highlight` outline shows inside its edge.
