# routines.triggers.lists-routines-that-start-it

- Status: draft
- Since: unreleased
- Source: HAL-1306 (T12 PR 15); flow-routines 2.3

The Triggers section shall list one row for each routine in the owner's hub that starts it, sorted by name, each with the trigger in words and then the routine's name and when it next starts, or the Off chip when it is off, and a row shall open the routine's page.

## Examples

- Given routines Daily (on, next Fri 07:30) and Inbox (off) that start the agent, then the section has two rows, Daily first, "Daily · next Fri 07:30" under its sentence, and Inbox with the Off chip.
