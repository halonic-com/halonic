# inbox.count

- Status: active
- Since: 0.1.0
- Source: HAL-1218; [ux-checklists-approvals](/HAL/issues/HAL-1250#document-ux-checklists-approvals) 2.5; microcopy 19.2

The Inbox's count shall be the number of its items, as a count signal that a screen reader hears as "N waiting".

## Examples

- Given two items,
  when the count is worked out,
  then it is the count 2, heard as "2 waiting".
- Given no items,
  when the count is worked out,
  then it is 0, so the sidebar shows and says nothing.
