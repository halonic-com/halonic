# plugins.plugin-settings-list

- Status: active
- Since: 0.1.0
- Source: HAL-1740; plugin screens design section 3 (HAL-1739); UX acceptance checklist 2 (HAL-1952)

The plugins feature shall add a **Plugins** section to Settings that shows the installed plugins and the ones that come with Halonic as the plugins list, and **Add plugin** when the app gives it a way to add one. Opening a plugin shall close Settings and open its page, in a new tab when asked.

## Examples

- Given Weather is installed,
  when the person opens Settings → Plugins and opens Weather,
  then Settings closes and Weather's page opens.
