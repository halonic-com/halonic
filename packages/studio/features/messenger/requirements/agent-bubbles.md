# messenger.agent-bubbles

- Status: active
- Since: unreleased
- Source: plan "Messenger live replies" (HAL-18743, sections 3.1 and 9, question 3), approved by the board on 25 Nov at 18:46; task HAL-18755

The Messenger shall show each of an agent's messages in a bubble on the start side, on a neutral surface that differs from the person's bubbles on the end side, with the agent's picture and "Name · 13:58" above the first bubble of each run (`messenger.chat-transcript`).

## Examples

- Given Chief wrote "Morning" at 9:00 and "Build is green" at 9:01, and the board answered "Thanks",
  when the board opens the chat,
  then Chief's two messages sit in bubbles on the start side under "Chief · 09:00", and "Thanks" sits in the board's bubble on the end side.
