# agents.list.find

- Status: draft
- Since: unreleased
- Source: HAL-1299 (T6 PR 2); microcopy 8.1

The agents feature shall offer each agent in Ctrl K's search by its name, id or description, labelled "Agent · hub name", and a **New agent** command that opens the Agents page with its New agent dialog.

## Examples

- Given the agent "Sorter" with the description "Sorts the inbox" in the hub "Acme", then searching "sort" or "INBOX" offers it as "Agent · Acme", and an empty search offers nothing.
- Given the user runs **New agent** from Ctrl K, then the Agents page opens.
