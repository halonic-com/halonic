# check-computer.lines

- Status: active
- Since: unreleased
- Source: HAL-13411; first-run-progress 4.2 and 9 on HAL-7986 (approved by the board on 19 Nov, HAL-7993), revision 3 (Sofia's notes on HAL-13416) and revision 6 (Default model names the provider, its sentences are Studio's: Liam on HAL-13411, 21 Nov); words check C691 rows 65 and 69 (HAL-16283: the Models page's "system keychain", the doctor's sandbox kind); `check-computer.report` for the marks

When Check this computer shows a line, it shall show its label, its mark as the report counts it (`check-computer.report`), its sentences, the first beside the label and the rest under it, each fix starting "Fix:", and its actions. The Harnesses, Network and Disk lines and a check that ran over its time limit shall use `halonic doctor`'s shared words (`words.doctor-lines`), with a capital first letter and without the CLI's `More:` link, and a sandbox that can't start Studio's sandbox words (`app.sandbox-start-words`), its reason and "Fix: *fix*"; a ready sandbox shall read "Ready · " and the sandbox's kind as `halonic doctor` names it ("Ready · Seatbelt"), or "Ready" when Studio can't tell which kind the agent host runs. The **Engine** line shall read "Running · *Halonic's version and system*" or "Not running". The **Workspace** line shall read, for the demo, "*name* demo · Studio can open it · Trusted."; else "*name* · Trusted.", "*name* · Test model only, no trust needed.", "*name* isn't trusted yet." with "Halonic asks once, before the first run. This is on purpose.", "*name* changed since you trusted it." with "Halonic asks again before the next run.", or "*name* has something Halonic can't trust."; then "Its files have *n* problems, so no run starts until they're fixed." and the doctor's own sentences for a Windows drive and too many files to watch. The **Models** line shall say each problem the host found ("*Ollama* isn't answering at `localhost:11434`." with "Fix: start *Ollama* on this computer, then check again."), each server that answers ("*Ollama* is answering at `localhost:11434` · *models* loaded · last test answered, *10:42*" or "· not tested yet"), each cloud provider's key ("*Anthropic*: key set · last test accepted, *10:42*", "· not tested yet", "*Anthropic*: no key yet." with "Fix: add its key on the Models page.", or "*Anthropic*: Halonic couldn't read its key from your system keychain." with "Fix: check that your system keychain is unlocked, then check again."), a failed last test in the model screen's own sentences, and "Built-in test model · no key or network needed" for Sample answers. The **Default model** line shall read "The demo's `default` points at *Anthropic*." or "points at *Ollama* on this computer.", with "Not checked until the Models line above works." when the Models line has its cause; "Points at *Anthropic*, but Local only is on for this workspace, so cloud models are refused." under Local only; and "The demo's `default` uses Sample answers.". The **Last run** line shall read "Stopped at “*step*” after *6.8* s: " and what stopped it, in the line's own words for a missing, refused or out-of-credit key, a busy, unreachable, missing or slow model, Local only, the sandbox and an untrusted workspace, else "the run failed. Open the run to see why."; when a line above shows the same cause, "Stopped at “*step*” after *6.8* s, because of the *Models* line above.". The **Google** line shall read "Setup for *address* is at step *n* of *m*, started *8 Nov*.", and the **Not checked** line "Not checked here: the sandbox and harnesses, because the demo doesn't use them." ("this workspace doesn't" outside the demo). Names from the workspace's files, a model server or a run's log shall be made printable. The actions shall be the doctor's (`doctorLineActions`): **Review** for a workspace that isn't trusted, **Pick another model** on Default model unless it uses Sample answers, **Open the run** on Last run; on Models, **Test again** when a key is stored or a server is used, **Check again** when a server is used, and **Open Models** while it is a problem; **Continue** and **Start over…** on Google; none on the others.

## Examples

- Given the first run after a key with no credit stopped the run at "Write reply" after 6.8 s,
  then Models is a problem saying "Anthropic accepted the key, but the account has no credit or is over its limit." and "Fix: add credit on Anthropic's site, then test again.", with Test again and Open Models; Default model is info, "The demo's `default` points at Anthropic." and "Not checked until the Models line above works."; and Last run is info, "Stopped at “Write reply” after 6.8 s, because of the Models line above.", with Open the run.
- Given the user's own workspace, not trusted yet, with Ollama at `localhost:11434` not answering,
  then Workspace is a warning, "My workspace isn't trusted yet." and "Halonic asks once, before the first run. This is on purpose.", with Review; and Models is a problem with Test again, Check again and Open Models.
- Given Ollama answering with llama3.2, and a last test that answered at 10:42,
  then Models reads "Ollama is answering at `localhost:11434` · llama3.2 loaded · last test answered, 10:42".
- Given the Disk line with 48 GB free,
  then it reads as `halonic doctor` says it, "48 GB free · Halonic uses 1.4 GB (run logs 1.1 GB)".
- Given a key Halonic can't read from a locked keychain,
  then Models reads "OpenAI: Halonic couldn't read its key from your system keychain." and "Fix: check that your system keychain is unlocked, then check again.".
- Given a ready sandbox on macOS,
  then Sandbox reads "Ready · Seatbelt", and "Ready" when Studio can't tell the kind.
