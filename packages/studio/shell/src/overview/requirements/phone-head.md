# shell.overview.phone-head

- Status: draft
- Since: unreleased
- Source: HAL-12214 (A7, from the UX check HAL-12213); UX checklist section 0 (phone)

When the window is a phone, the overview page shall give the search field the whole line, so its placeholder isn't cut, and put the feature's create button under it at 48px high.

## Examples

- Given the window is a phone and the feature passes a "New skill" button, then the button is 48px high and sits under the search field.
- Given the window is a desktop, then the button stays after the search field on the same line.
