# Decision: move sandbox-runtime from 0.0.81 to 0.0.82

- Approval: HAL-9557. Liam approves this note in review of this PR.
- Kind: internal
- Task: HAL-9557

## What changes

- The catalog pin of `@anthropic-ai/sandbox-runtime` is exactly `0.0.82`, and the lockfile moves with it.
- The Halonic patch is cut again for 0.0.82 (same three changes: `denyMachLookup` on macOS and the Windows loopback probe). Its file name, its hash in `patches-allowed.json` and the check's own test follow.
- The SHA-256 of `srt-win.exe` built into `sandbox-elevate` is the hash of the 0.0.82 file, for x64 and arm64.
- `ignoredOptionalDependencies` keeps `@microsoft/mxc-sdk` out of the install. 0.0.82 lists it as an optional dependency, and the user approved that SDK only as a one-time download by the MXC adapter, not as a package dependency (HAL-7606).
- The tested-version lists in `sandbox-srt` and the version strings in tests follow.

## Why

The WSL2 release check (HAL-196) ran on 0.0.82, so the repo ships what was checked (HAL-9556, option b).
