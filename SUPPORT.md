# Getting help

Halonic is a community project before version 1.0. There is no paid support
yet, but there are good places to ask.

| You want to… | Go to |
| --- | --- |
| ask a question | [**Q&A** in GitHub Discussions](https://github.com/halonic-com/halonic/discussions/new?category=q-a) |
| report a bug | a new issue, using the **Bug report** form |
| tell us installing or the first run didn't work | a new issue, using the **Install problem** form |
| suggest a feature | a new issue, using the **Idea or feature request** form, or a discussion in **Ideas** if it's still an idea |
| ask for an integration with another service | a new issue, using the **Integration request** form |
| share an idea or show what you built | **Ideas** or **Show and tell** in [GitHub Discussions](https://github.com/halonic-com/halonic/discussions) |
| report a mistake or gap in the docs | a new issue, using the **Docs problem** form |
| report a security problem | **not** an issue: follow [SECURITY.md](SECURITY.md) |
| report behaviour that breaks our [code of conduct](CODE_OF_CONDUCT.md) | [conduct@halonic.com](mailto:conduct@halonic.com) |

GitHub Discussions is our only community channel for now. When you are not
sure where a question belongs, start in
[Q&A](https://github.com/halonic-com/halonic/discussions/new?category=q-a).
There is no Discord or chat server, so anything that claims to be one isn't
ours.

## Before you ask

- Read the pinned Known issues in 0.1.0 issue.
- Search the existing issues and discussions. Someone may have asked already.
- Check that you're on the latest release.

## When you ask

Say what you did, what you expected and what happened instead. Include the
Halonic version you use and your operating system.

If you share a workspace to show the problem, make a small one with made-up
content. Never post API keys, passwords or personal data.
