# Config keys that run a program or read a file

Anyone who can write an opened folder can write `.git/config`. This list has every key in `git help config` for git 2.47 that runs a program or reads a file or folder, and says how the runner handles it. It backs requirement `repo-config` (HAL-1930).

How a key is handled:

- **Hardening config**: the runner sets the key on every call, in `GIT_CONFIG_COUNT`, which beats every config file (`HARDENING_CONFIG` in `src/runner.rs`).
- **Environment**: a variable the runner sets beats the key (`HARDENING_ENVIRONMENT`).
- **Flag**: an argument the runner adds beats the key (`hardened_command`).
- **Allow-list**: no allowed call reaches the key (`src/allow_list.rs`, `src/check_args.rs`).
- **Neutralised**: the repository's value is replaced on each call (`src/repo_config.rs`).
- **Refused**: a repository whose own config sets the key is refused with `config_not_allowed` (`check_refused_keys` in `src/repo_config.rs`).
- **Not reachable**: no allowed subcommand reads the key.
- **Accepted**: the key is read, and the reason it does no harm is given.

## Keys that run a program

| Key                                                                                                                                                          | Handling                                                  | Why it holds                                                                                                                                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `alias.*`                                                                                                                                                    | Not reachable                                             | Every allowed subcommand is a built-in, and an alias never replaces a built-in.                                                                                                                                                             |
| `browser.<tool>.cmd`, `browser.<tool>.path`, `web.browser`, `help.browser`, `help.htmlPath`, `man.<tool>.cmd`, `man.<tool>.path`, `man.viewer`, `instaweb.*` | Not reachable                                             | `help`, `instaweb` and `web--browse` aren't allowed.                                                                                                                                                                                        |
| `core.alternateRefsCommand`                                                                                                                                  | Hardening config `true`                                   | `pull` would run it for every alternate. `true` names no refs; only a fetch shortcut is lost.                                                                                                                                               |
| `core.askPass`                                                                                                                                               | Environment `GIT_ASKPASS=`                                | An empty `GIT_ASKPASS` beats the key, and git then asks no program.                                                                                                                                                                         |
| `core.editor`, `sequence.editor`                                                                                                                             | Environment `GIT_EDITOR=true`, `GIT_SEQUENCE_EDITOR=true` | The variables beat the keys.                                                                                                                                                                                                                |
| `core.fsmonitor`                                                                                                                                             | Hardening config `false`                                  |                                                                                                                                                                                                                                             |
| `core.gitProxy`                                                                                                                                              | Environment `GIT_ALLOW_PROTOCOL=https:ssh`                | It is only used for `git://`, which is refused.                                                                                                                                                                                             |
| `core.hooksPath`, and every hook                                                                                                                             | Hardening config: an empty folder                         | The runner checks the folder is empty before every call.                                                                                                                                                                                    |
| `core.pager`, `pager.<cmd>`                                                                                                                                  | Flag `--no-pager`, environment `GIT_PAGER=cat`            |                                                                                                                                                                                                                                             |
| `core.sshCommand`                                                                                                                                            | Neutralised                                               | It falls back to the user's own value, or `ssh`. `GIT_SSH` and `GIT_SSH_COMMAND` are removed with every other `GIT_*` variable.                                                                                                             |
| `credential.helper`, `credential.<url>.helper`                                                                                                               | Neutralised                                               | The helper list is cleared and only the user's own helpers go back on.                                                                                                                                                                      |
| `diff.external`, `diff.<driver>.command`, `diff.<driver>.textconv`                                                                                           | Flag `--no-ext-diff --no-textconv` on `diff` and `log`    | No other allowed call shows a diff: `commit` never opens an editor (see `commit.template`), so `commit.verbose` shows nothing.                                                                                                              |
| `diff.submodule`                                                                                                                                             | Hardening config `short`                                  | `diff` would otherwise run `git diff` inside each submodule, without the flags above.                                                                                                                                                       |
| `diff.tool`, `diff.guitool`, `difftool.*`, `merge.tool`, `merge.guitool`, `mergetool.*`                                                                      | Not reachable                                             | `difftool` and `mergetool` aren't allowed.                                                                                                                                                                                                  |
| `filter.<driver>.clean`, `.smudge`, `.process`                                                                                                               | Neutralised                                               | Blanked, for the repository and for every repository nested in it as a gitlink.                                                                                                                                                             |
| `gc.recentObjectsHook`                                                                                                                                       | Hardening config `maintenance.auto=false`, `gc.auto=0`    | Only `gc`, `repack` and `prune` run it, and the allow-list reaches those only through automatic maintenance after `commit` or `pull`. With maintenance off, `gc.autoDetach` and `maintenance.autoDetach` don't matter either.               |
| `gpg.program`, `gpg.<format>.program`, `gpg.ssh.defaultKeyCommand`                                                                                           | Neutralised, and hardening config turns signing off       | `log --format=%G?`, a `format.pretty` alias or `branch --format=%(signature)` still checks signatures, with the user's own or git's default program.                                                                                        |
| `guitool.*`                                                                                                                                                  | Not reachable                                             | `gui` and `citool` aren't allowed.                                                                                                                                                                                                          |
| `imap.tunnel`                                                                                                                                                | Not reachable                                             | `imap-send` isn't allowed.                                                                                                                                                                                                                  |
| `interactive.diffFilter`                                                                                                                                     | Not reachable                                             | Only `add -p` uses it, and `-p` isn't allowed on `add`.                                                                                                                                                                                     |
| `merge.<driver>.driver`                                                                                                                                      | Neutralised                                               | Replaced by `exit 1`, so the merge reports a conflict.                                                                                                                                                                                      |
| `remote.<name>.uploadpack`                                                                                                                                   | Flag `--upload-pack=git-upload-pack` on `pull`            |                                                                                                                                                                                                                                             |
| `remote.<name>.receivepack`                                                                                                                                  | Flag `--receive-pack=git-receive-pack` on `push`          |                                                                                                                                                                                                                                             |
| `remote.<name>.vcs`, `remote.<name>.url` as `<transport>::…`, `url.<base>.insteadOf`, `url.<base>.pushInsteadOf`                                             | Environment `GIT_ALLOW_PROTOCOL=https:ssh`                | Any other helper or transport (`ext`, `file`, `fd`, `git`) is refused when git connects.                                                                                                                                                    |
| `sendemail.*`                                                                                                                                                | Not reachable                                             | `send-email` isn't allowed.                                                                                                                                                                                                                 |
| `ssh.variant`                                                                                                                                                | Accepted                                                  | It picks which options git passes to ssh and runs nothing itself. git refuses a host that starts with `-`.                                                                                                                                  |
| `submodule.<name>.update` (`!command`)                                                                                                                       | Not reachable                                             | `submodule` isn't allowed, and hardening config keeps git out of submodules.                                                                                                                                                                |
| `uploadpack.packObjectsHook`, `receive.procReceiveRefs`, a remote's hooks                                                                                    | Not reachable                                             | The server's git runs them, with its own config. A local remote would run them here, which is why the `file` transport is refused. git reads `uploadpack.packObjectsHook` only from protected config (system, global, command line) anyway. |
| `trailer.<token>.cmd`, `trailer.<token>.command`                                                                                                             | Not reachable                                             | Only `commit --trailer` and `interpret-trailers` run it, and neither is allowed.                                                                                                                                                            |
| `trace2.normalTarget`, `trace2.perfTarget`, `trace2.eventTarget`                                                                                             | Not reachable                                             | git reads them only from system and global config, and system config is off.                                                                                                                                                                |

## Keys that read a file or folder

| Key                                                                                                                                                                                    | Handling                                            | Why it holds                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `commit.template`                                                                                                                                                                      | Allow-list                                          | `commit` needs `-m` or `--message`, or `--amend --no-edit`. Otherwise the file would become the message and a `push` would send it out. A `pull` merge doesn't read it (tested with 2.47), but it reads `branch.<name>.mergeOptions` (see below).                                  |
| `branch.<name>.mergeOptions`                                                                                                                                                           | Refused                                             | The `git merge` that `pull` runs reads it as options, so `-F <file>` would make any file the merge commit's message, ready to push. An empty value in `GIT_CONFIG_COUNT` doesn't override it (tested with 2.47), so the repository is refused. The user's own value still applies. |
| `fetch.bundleURI`                                                                                                                                                                      | Hardening config, empty                             | `pull` would read a bundle from any file and add its objects and refs, ready to push. `bundle.*` lists come only from a bundle URI, and `transfer.bundleURI` only applies to `clone`, which isn't allowed.                                                                         |
| `include.path`, `includeIf.<condition>.path`                                                                                                                                           | Followed, then neutralised                          | The listing uses `--includes`, and every entry from an included file counts as the repository's. A file that isn't config makes the listing fail, so the call is refused with `repository_unreadable`.                                                                             |
| `core.worktree`                                                                                                                                                                        | Flag `--work-tree`                                  | The runner gives the checked top folder.                                                                                                                                                                                                                                           |
| `core.excludesFile`, `core.attributesFile`                                                                                                                                             | Accepted                                            | Read only as ignore or attribute patterns, which the repository's `.gitignore` and `.gitattributes` can set anyway. Nothing of the file is shown or written, and attributes only pick filters and drivers, which are neutralised.                                                  |
| `diff.orderFile`                                                                                                                                                                       | Accepted                                            | Read only to order the diff the Studio shows.                                                                                                                                                                                                                                      |
| `mailmap.file`, `mailmap.blob`                                                                                                                                                         | Accepted                                            | Only changes the names `log` shows. The blob comes from the repository itself.                                                                                                                                                                                                     |
| `fsck.skipList`, `fetch.fsck.skipList`                                                                                                                                                 | Accepted                                            | Read only as object names to skip in checks.                                                                                                                                                                                                                                       |
| `gpg.ssh.allowedSignersFile`, `gpg.ssh.revocationFile`                                                                                                                                 | Accepted                                            | Read only by the user's own or git's default `ssh-keygen`, for a signature check shown on screen.                                                                                                                                                                                  |
| `user.signingKey`                                                                                                                                                                      | Not reachable                                       | Signing is off.                                                                                                                                                                                                                                                                    |
| `http.sslCert`, `http.sslKey`, `http.sslCAInfo`, `http.sslCAPath`, `http.proxySSLCert`, `http.proxySSLKey`, `http.proxySSLCAInfo`, `http.pinnedPubkey`, and their `http.<url>.*` forms | Accepted                                            | Read by the TLS library to connect to the remote, which the repository's config names anyway. A key never leaves the machine, and a certificate is public by design.                                                                                                               |
| `http.cookieFile`                                                                                                                                                                      | Accepted; hardening config `http.saveCookies=false` | curl sends a cookie only to the domain it belongs to, and never writes the file.                                                                                                                                                                                                   |
| `init.templateDir`                                                                                                                                                                     | Not reachable                                       | `init` reads it before the repository's config, so only the user's own value applies (tested with 2.47).                                                                                                                                                                           |
| `blame.ignoreRevsFile`, `format.signatureFile`, `format.outputDirectory`, `sendemail.aliasesFile`, `sendemail.smtpSSLCertPath`, `gitcvs.logFile`, `gitcvs.dbName`                      | Not reachable                                       | `blame`, `format-patch`, `send-email` and `cvsserver` aren't allowed.                                                                                                                                                                                                              |
| `receive.fsck.skipList`                                                                                                                                                                | Not reachable                                       | Only the server's git reads it.                                                                                                                                                                                                                                                    |

## Other keys that matter

| Key                                                 | Handling                                   | Why it holds                                                                                                                                                                                                                           |
| --------------------------------------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `protocol.allow`, `protocol.<name>.allow`           | Environment `GIT_ALLOW_PROTOCOL=https:ssh` | The variable beats both keys.                                                                                                                                                                                                          |
| `remote.<name>.promisor`, `extensions.partialClone` | Accepted                                   | In a partial clone, `diff`, `log` and `checkout` may fetch missing objects from the promisor remote. That is network use the call didn't ask for, but only over https or ssh, with the neutralised ssh command and credential helpers. |
| `safe.directory`                                    | Not reachable                              | git reads it only from protected config (system, global, command line), so a repository can't set it.                                                                                                                                  |

## On a git upgrade or a new allowed call

Compare `git help config` of the new release with this list, and check every new key that runs a program or reads a file. Do the same when a subcommand or option goes onto the allow-list: a key marked "Not reachable" may become reachable.
