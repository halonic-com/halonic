# studio.window-appearance

- Status: active
- Since: 0.1.0
- Source: HAL-1294 (T11); HAL-7216; flow-settings 5 (HAL-646)

The desktop app shall give every workspace in a window the same display settings, saved on this computer, and show their Appearance on the whole window (`settings.appearance-section`) from the moment it starts until it stops.

## Examples

- Given the desktop app, with the theme Dark saved on this computer,
  when it starts,
  then the window shows the Dark theme.
