# Short title: the decision as a sentence

- **Status:** Proposed | Accepted | Replaced by [title](YYYY-MM-DD-short-title.md)
- **Date:** YYYY-MM-DD

## Context

What problem or force made us decide? Two to five sentences. Name the
alternatives we looked at, if there were any.

## Decision

What we decided, in the present tense: "Agents name a model alias." Be specific
enough that a reviewer can tell whether a change follows it.

## Consequences

What gets easier, what gets harder, and which checks or tests keep the decision
true. Name what changes for contributors.

## Changed from an earlier decision

Optional. Use it when this record replaces or changes an earlier one: what was
decided before, and what is different now.
